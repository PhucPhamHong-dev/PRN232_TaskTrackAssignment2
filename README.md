# PRN232 TaskTrack Assignment 2

TaskTrack Assignment 2 extends the public task-management application with JWT authentication, role-based access control, protected administration, refresh tokens, account management, and profile features.

## Structure

- `backend` - ASP.NET Core 8 Web API, service layer, repository layer, and Docker deployment.
- `frontend` - Next.js 16 App Router application written in TypeScript.
- `database` - PostgreSQL migration and account-seeding scripts.
- `docs` - deployment and verification notes.

Assignment 1 remains available separately and is not modified by this repository.
